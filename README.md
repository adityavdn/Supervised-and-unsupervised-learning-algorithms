# 📚 Supervised & Unsupervised Learning Algorithms

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![ML](https://img.shields.io/badge/Machine_Learning-Algorithms-orange.svg)

## 📖 Overview

Comprehensive implementation and comparison of supervised and unsupervised machine learning algorithms. Includes classification, regression, clustering, and dimensionality reduction techniques with real-world datasets.

## 🎯 Algorithms Covered

**Supervised Learning:**
- Linear/Logistic Regression
- Decision Trees, Random Forest
- SVM, KNN, Naive Bayes
- Gradient Boosting (XGBoost)

**Unsupervised Learning:**
- K-Means, DBSCAN
- Hierarchical Clustering
- PCA, t-SNE
- Association Rules

## 🛠️ Tech Stack

- Scikit-learn, XGBoost
- Pandas, NumPy
- Matplotlib, Seaborn

## 🚀 Usage

```bash
git clone https://github.com/adityavdn/Supervised-and-unsupervised-learning-algorithms.git
cd Supervised-and-unsupervised-learning-algorithms
pip install -r requirements.txt
jupyter notebook
```
